# 화풍 조각 → VFX 프로필 대응표

`vfxtool profile --style <화풍 조각.json>` 이 읽는 키 목록이다. **아는 키만 읽고 나머지는 무시한다.**
ArtTool 쪽 형식이 바뀌면 이 표와 `src/vfxtool/profile/style.py` 의 `STYLE_KEYS` 만 고친다. ArtTool 코드는 import 하지 않는다.

## 대응표

| 화풍 조각 키 | 프로필 칸 | 받는 꼴 | 바꾸는 법 |
| --- | --- | --- | --- |
| `palette` | `palette` | hex 배열, 또는 `{"colors": [hex, …]}` | 대문자 `#RRGGBB(AA)` 로 다듬고 겹친 색은 뺀다. 최대 32 |
| `ppu` · `pixels_per_unit` | `ppu` | 양의 정수 | 그대로. 둘 다 있으면 `pixels_per_unit` 이 이긴다 |
| `pixel_size` | `pixel_size` | 정수, 또는 정수 배열 | 오름차순 집합으로 |
| `max_colors` | `max_colors` | 양의 정수 | 그대로 |
| `frame_ms` | `fps` | 양수(ms) | `round(1000 / frame_ms)` |
| `fps` | `fps` | 양의 정수 | 그대로. `frame_ms` 보다 이긴다 |
| `fps_range` | `fps_range` | `[min, max]` | min ≤ max 확인 |
| `outline` | `outline` | `"none"` 만 | 이펙트는 외곽선을 안 쓴다(설계 3-1). 다른 값이면 warn 하고 건너뛴다 |

- **값이 틀리면** 그 키만 `profile.style_value` warn 으로 건너뛴다. 화풍 조각은 남의 산출물이라 멈추지 않는다.
- **모르는 키**는 보고 `metrics.style_ignored` 에 이름만 남긴다.
- 표에 없는 칸(`fx_extra` · `alpha_steps` · `allow_rotation` · `seq_tolerance` 등)은 손 덮기(`--override`)로만 넣는다.

## 이기는 순서

기본값 < 기준 PNG < 화풍 조각 < 손 덮기. 칸마다 어디서 왔는지 `profile.json` 의 `source` 에 `default` · `png` · `style` · `override` 로 적힌다.
칸과 기본값은 설계 `../Design/2026-10-14-VFX툴설계.md` 3절을 본다.
