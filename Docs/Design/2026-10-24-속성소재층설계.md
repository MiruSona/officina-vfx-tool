## 0. 결론 먼저

- 새 소재 `bolt16` 하나를 만든다. 16×16 칸 · 10장 플립북 `[10,1]` · 흰 1단 · alpha. 지그재그 번개 줄기 1개 + 갈래 1개가 내려와 번쩍이고 깜빡이다 사라진다.
- 생성은 `lib_draw.py` 에 ring 과 같은 「규칙 그리기」 가지를 하나 더해서 한다. 꼭짓점이 고정이라 난수가 없고, 늘 같은 픽셀이 나온다. 굽기는 `vfxtool lib build --only bolt16`.
- `variants/lightning.json` 의 `materials` 에 `"lib:puff16": "lib:bolt16"` 한 줄을 더한다. 이 치환이 닿는 템플릿은 land_dust 하나다.
- 치환 코드는 kind · tiles 가 같아야 받는다(`variant_expand._substitute`). puff16 과 bolt16 은 둘 다 `flipbook [10,1]` 이라 통과한다. 크기 칸(`puff_size`)은 bolt16 의 칸 16 으로 자동으로 맞춰진다. **Unity · C# · resolve 는 안 바꾼다.**
- 두 톤은 색이 아니라 밀도로 낸다. 촘촘한 1px 심 줄기 + 번쩍 장에만 붙는 성긴 곁점이다. 회색 단은 팔레트 밖 색이 되어 이미 기각된 길이다(burst16 2단 `palette_out_mean` 0.4545).
- 실측은 실물 Unity 묶어 굽기 2판이다. land_dust × lightning × strong 이 「번개로 보이나」를 보고, hit_sparks × lightning × mid 가 「다른 데가 안 바뀌었나」를 본다.

## 2. 소재 bolt16 규칙

### 2-1. 꼴

| 칸 | 값 | 까닭 |
| --- | --- | --- |
| 칸 | 16 | puff16 과 같은 칸이라 `puff_size` 16 이 그대로다. 소재 칸의 정수 배 규칙(mem caution)도 지킨다 |
| tiles · frames · rows | `[10, 1]` · 10 · 1 | 치환은 tiles 가 같아야 받는다. land_dust 의 puff 층은 수명 0.833초 · 초당 12장 · 1바퀴라 딱 10장이다 |
| kind | `flipbook` | |
| 블렌드 권장 | `alpha` | additive 는 겹친 칸이 팔레트 밖으로 나간다(실험 2). 템플릿 층도 alpha 다 |
| 픽셀 | 칠한 칸은 (255,255,255,255), 빈 칸은 (0,0,0,0)만 | 다른 기하 소재와 같은 흰 1단이다. 반투명 칸이 없으니 `frame.semi_alpha` 도 안 난다 |
| 메타 | `made: "draw"` · `source: null` · `license: "MIT (VFXTool 생성)"` · `tones` 칸 없음 | `lib_draw.meta()` 가 그대로 만든다 |

### 2-2. 모양 (좌표는 칸 안에서 x 오른쪽 · y 아래, 0 ~ 15)

- 줄기 꼭짓점 : A(7,0) → B(5,4) → C(9,7) → D(6,11) → E(9,15). 4마디 지그재그다.
- 갈래 : C(9,7) → F(12,9) → G(14,12).
- 마디는 Bresenham 선(8방향 이웃)으로 긋는다. 굵기는 1px.
- 곁점(옅은 외곽) : 줄기 픽셀 가운데 y 가 짝수인 칸의 오른쪽 한 칸 (x+1, y). 번쩍 장에서만 붙는다.

| 장 | 그림 | 뜻 |
| --- | --- | --- |
| 0 | A→B | 머리가 내려온다 |
| 1 | A→B→C→D | 거의 다 내려옴 |
| 2 | 줄기 전체 + 갈래 + 곁점 | 번쩍 |
| 3 | 줄기 전체 + 갈래 + 곁점 | 번쩍 유지 |
| 4 | 줄기 전체 + 갈래 | 곁점이 꺼짐 |
| 5 | 빈 장 | 깜빡 |
| 6 | 줄기 전체 | 다시 침(갈래 없음) |
| 7 | 마디 A→B · C→D 만 | 끊김 |
| 8 | 줄기 픽셀 세 칸마다 하나 | 흩어짐 |
| 9 | 빈 장 | 끝. 효과 마지막 장이 비게 돕는다(`frame.last_not_empty`) |

### 2-3. 코드 자리 (`lib_draw.py`)

ring 의 구조를 그대로 따른다. 새 추상화는 없다.

- `_line(p, q)` : Bresenham 점 집합. `midpoint_circle` 옆에 둔다.
- `_bolt_frames()` : 위 표의 10장을 점 집합 목록으로 돌려준다. 꼭짓점은 모듈 상수다.
- `spec("bolt16")` : `return 16, [], "alpha", [[_points_to_art(p, 16) for p in _bolt_frames()]]`. ring 가지 바로 아래에 둔다.
- `names()` : `sorted(list(ART) + ["ring", "bolt16"])`.
- 모듈 docstring 의 「기하 소재 7종」을 「8종(규칙 그리기 ring · bolt16)」으로 고친다.
- `render` · `meta` · `build` 는 그대로다. `--only bolt16` 도 지금 코드로 된다.

결정성 : 난수를 안 쓴다. 「시드 고정」보다 강하게, 같은 코드면 늘 같은 바이트가 나온다. 시험 `test_build_twice_same_pixels_and_matches_repo` 가 이것을 본다.

### 2-4. 굽는 명령 · 출처

- `python -m vfxtool lib build --only bolt16` (VFXTool 루트에서). `lib/bolt16.png` 는 160×16, `bolt16.json` 은 메타다.
- **sources.json 에는 줄을 안 적는다.** sources.json 은 자른 소재(`made: "cut"`)의 원본 기록이다. `test_cut_materials_listed_in_sources` 도 자른 소재만 본다. 만든 소재는 메타의 license 칸이 출처다.

## 3. 사전 · 템플릿 영향

`lightning.json` 의 `materials` 는 `{ "lib:shard": "lib:streak", "lib:ring": "lib:star4", "lib:puff16": "lib:bolt16" }` 가 된다.

| 템플릿 | puff16 을 쓰나 | 치환 결과 | 말이 되나 |
| --- | --- | --- | --- |
| land_dust | `puff_tex` 기본 (puff_l · puff_r) | 좌우 연기 뭉치 → 번개 줄기. `puff_size` 16 그대로. strong 은 count 2 × 1.5 → 한쪽 3개 | 된다. 다만 층의 옆 속도(x ±15 ~ 19)와 오름 속도는 그대로라 번개가 옆으로 13 ~ 16px 미끄러진다. 눈으로 본다(위험 R1) |
| hit_sparks | 안 쓴다(`smoke_tex` 는 puff8, `core_tex` 는 burst16) | 없음. info `variant.unused_material` 「안 쓴 치환 lib:puff16」 하나가 는다 | 번개 모양은 안 들어간다. 이 판은 다른 데가 안 바뀌었는지 보는 관문이다 |
| ambient_motes · heal_rise · sparkle | 안 쓴다 | 그 판들에서도 info 하나가 는다 | 영향 없음 |

- **puff8** : hit_sparks `smoke` 층(기본 꺼짐)만 쓴다. 번개 효과에도 연기는 연기로 두면 된다. `bolt8` 은 **이번 판 밖**이다.
- burst16 → 번개 : tiles 가 [5,1] 이라 bolt16 [10,1] 과 다르다. 치환하면 `variant.material` 실패가 난다. 넣지 않는다(7절).

## 4. Unity 쪽

- 고칠 것이 없다. `resolve.fill_lib_sheet` 가 메타 tiles `[10,1]` 을 `textureSheet.tiles` 에 채운다. fps 12 · cycles 1 은 템플릿 층 값이 그대로 남는다. C# 은 resolved.json 의 tiles 만 읽는다.
- 프레임 수는 puff16 과 같은 10이라 맞출 것이 없다. 치환 코드가 다른 수를 막으니, 다른 수의 소재는 펼치기 단계에서 실패로 걸린다.
- 크기 : `pair_values` 가 `puff_size` 를 bolt16 의 칸 × 세기 scale 로 채운다. land_dust 세기에는 scale 이 없어 16이다.

## 6. 실측 관문

실물 Unity(시험 Unity 프로젝트), 10-22 묶어 굽기 기본 경로(`variant run`, `--each` 없음)로 돈다. 묶음은 템플릿이 하나라 두 묶음 · Unity 두 번이다.

| 판 | 묶음 |
| --- | --- |
| `land_lightning_strong` | land_dust · attrs lightning · tiers strong · seeds 1 · seed 1000 |
| `hit_lightning_mid` | hit_sparks · duration 0.6 · `params.ring: true` · attrs lightning · tiers mid · seeds 1 · seed 1000 (10-22 묶음과 같은 값) |

차례 : (1) 구현 전 HEAD 에서 hit 묶음을 `variant expand` 만 해서 resolved.json 을 떠 둔다. (2) 구현 → `lib build --only bolt16` → pytest. (3) 두 묶음을 expand → run → sheet.

| 관문 | 수치 기준 | 눈 기준(접촉판 · gif) |
| --- | --- | --- |
| B1 land | state `done` · warn 0 · `frame.palette` warn 0 · `palette_dist` 최대 ≤ 4.0 · `frame.semi_alpha` · `frame.last_not_empty` 없음 · notes 에 「안 쓴 치환 lib:puff16」 없음. 장 수 · coverage 는 10-15 밤 판(22장 · warn 0)과 나란히 적는다(줄어드는 게 맞다) | 좌우에 지그재그 줄기가 보이고, 번쩍(장 2 ~ 3) → 깜빡 → 다시 침 → 흩어짐이 읽힌다. 「연기 원판」으로 안 보인다. 미끄러짐이 거슬리는지 적는다(R1) |
| B2 hit | state `done` · warn 0 · resolved.json 이 (1) 에서 떠 둔 것과 바이트 같음 · notes 에 「안 쓴 치환 lib:puff16」 info 가 하나 늚 | 10-22 hit 묶음 lightning 판과 같은 모양(바뀐 게 없어야 한다). V4(star4 고리가 작다)도 이때 같이 본다 |

B1 의 눈 기준은 사람이 정한다. AI 가 본 것은 「AI 눈」이라고 적는다.
