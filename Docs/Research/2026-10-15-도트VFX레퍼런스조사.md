# 도트 VFX 레퍼런스 조사 — 좋은 도트 이펙트는 어떻게 생겼나 (2026-10-15)

**한 줄 요약** : 세 조사가 모두 짚은 것은 **「짧게 · 앞이 빠르게 · 첫 장 흰 번쩍 · 색은 적게 끊어서 · 반투명 말고 작아지며 사라짐」** 이다.
우리 툴은 이미 색·알파를 끊어 쓰고(Gradient Fixed) 크기 곡선도 계단이다. **가장 크게 어긋난 값은 hit_sparks 파편 수(18 → 출처는 3~8)와 「흰 번쩍 층이 없음」 · 「수명에 따라 색이 안 바뀜」** 이다.
그림은 아무도 못 봤다. 다음 일은 사람이 Saint11 GIF 몇 장을 직접 보는 것이다.

## 조사 방식과 한계

| 항목 | 내용 |
| --- | --- |
| 방식 | 같은 질문을 조사 셋(A · B · C)이 서로 모르게 따로 웹 조사(질의 각 20~26개) → 이 문서로 합침 |
| 무게 | **셋이 다 찾은 것을 높게, 하나만 찾은 것은 낮게** 본다. 「찾은 판」 열이 그 수다 |
| 확신도 | **[본문]** 페이지 글을 직접 읽음 · **[검색]** 검색 요약만 봄 · **[추측]** 출처 없는 판단 (원본 셋의 표기를 이 셋으로 맞춤) |
| 한계 1 | **셋 다 그림 · GIF 를 하나도 못 봤다.** 도트 VFX 지식은 대부분 GIF · 시트로 퍼져 있어서, 모양 묘사는 글 설명 + 추측이다 |
| 한계 2 | **한국어 자료 0건** (셋 합쳐 한국어 질의 약 8번) |

| 날짜 | 2026-10-15 · 기준 fps 는 우리 툴의 12fps (1프레임 ≈ 83ms) |

## 3. 템플릿 다섯 — 레퍼런스 꼴 ↔ 우리 지금 값

우리 값은 `VFXTool/src/vfxtool/templates/*.json` 기본값. 알파 · 색 그라디언트는 Fixed(끊김)라 반투명 중간 단계는 이미 없다.

### 3-1. hit_sparks (타격 파편)

| 항목 | 레퍼런스 꼴 | 우리 지금 |
| --- | --- | --- |
| 길이 | **3~6장**(Pixnote) · 4~6장 [추측] · 임팩트 장 **2장 홀드**(Sprite AI) | 수명 0.3~0.5초 = 4~6장 · 홀드 없음 |
| 첫 장 | **흰 덩어리 1~2장**(GamineAI · GDevelop), 원 · 별 4~8px [추측] | **없음** |
| 파편 수 | **3~8**(GamineAI) | **18** (small 10 · big 32) |
| 모양 | 진행 방향으로 늘어난 2~3px 줄기, 점으로 짧아짐 [추측] | 점(2px → 0.4 에서 1px) · Stretched 미지원 |
| 퍼짐 | 사방 방사 [추측] | 위쪽 원뿔 반각 35° · 중력 0.6 |
| 속도 | 1장에 거리 대부분, 급감속 [추측] | 시작 속도 무작위(40~90) · 감속 없음 |
| 색 | 흰 → 노랑 → 주황(→ 빨강) 3단 [추측] · 빠를수록 흰색(Unity 예) | 한 색(p0) 고정 |

### 3-2. sparkle (반짝임)

| 항목 | 레퍼런스 꼴 | 우리 지금 |
| --- | --- | --- |
| 모양 | **+ 모양 4점 별**, 돌다가 크게 번쩍(PixelJoint) | 플립북 시트(4칸) — 그림은 시트 몫 |
| 순서 | 1px 점 → 작은 + → 큰 별 → 작은 + → 꺼짐, 4~6장 [추측] | 시작 칸이 **무작위(0~4)** 라 중간부터 시작하는 별이 있음 |
| 수 | 동시 1~5개, 서로 다른 때 켜짐(0.25초씩 깜빡 [검색]) | 초당 6 · 수명 0.5초 → 동시 약 3개 |

### 3-3. land_dust (착지 먼지)

| 항목 | 레퍼런스 꼴 | 우리 지금 |
| --- | --- | --- |
| 방향 | **좌우 두 갈래 수평**, 위로는 거의 안 뜸(weenter 팩 분류 [본문] + 추측) | Edge 가로선 + radial 10~24 + 위로 3~6 텍셀/초 |

| 덩어리 | 둥근 퍼프 한쪽 2~3개, 3~4px → 1px [추측] | 알갱이 12개 · 2px → 1px |
| 속도 | 빠르게 시작해 급감속(마찰 큼) [추측] | 일정 속도 |
| 색 | **흰 · 연한 갈색 두 벌**(Flashy Feather), 위 밝고 아래 어둡게 2~3단 [추측] | 한 색(p1) |

**셋이 같은 결론** : 도트 VFX 도구는 모두 「시뮬 → 도트화 + 팔레트 제한 → 시트로 굽기」다. Shuriken 파라미터로 내 주는 도구는 없다.
그래서 우리 길(레시피 → Shuriken → 12fps 저해상도 렌더)은 Pixel FX Designer 와 같은 방향이고, **그 도구의 기능 목록(팔레트 제한 · 디더 · 입자 모양 · 외곽선)이 우리가 가질 손잡이 목록**이라는 것이 A · C 의 판단이다 [추측].

## 5. 손질 후보

4. **C# 묶음(H3 · H4 · H5 · H15)은 2차 모듈 판으로** — 미지원 목록에서 꺼내는 일이라 설계 2-3 을 같이 고쳐야 한다.
